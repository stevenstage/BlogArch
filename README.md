## 📌 关于本项目

本仓库系统梳理 **Foundation Model 在电力电子（Power Electronics）领域的应用与研究**，涵盖：

- 🔧 **论文精读**：深度解析时序建模、大语言模型、稀疏注意力等关键技术
- 🧠 **研究进展**：预训练模型迁移、学习动力学、工况解耦等前沿探索  
- 🚀 **Idea 生成**：跨领域创新思路与实验洞察
